# Security

Nara Studio is an experimental localhost application. Do not expose its server port directly to the internet. Alpha status is not a guarantee of production security or stability.

Do not disclose credentials, cookies, tokens, or sensitive exploit details in public issues. If the repository offers **Security > Report a vulnerability**, use that channel. Otherwise, ask the repository owner to provide a private contact before sharing sensitive details.

Redact logs and screenshots. If a credential is accidentally published, revoke or rotate it with its provider; deleting it from the latest commit does not remove Git history.

Keep local data, voice references, browser sessions, and personal configuration out of source distributions. See `.gitignore` and `THIRD-PARTY-NOTICES.md`.
