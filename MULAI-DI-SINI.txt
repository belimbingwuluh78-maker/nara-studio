NARA STUDIO — MULAI DI SINI

1. Ekstrak seluruh ZIP ke satu folder di komputer Windows.
2. Pastikan Node.js 22 atau lebih baru dan Microsoft Edge/Google Chrome sudah terpasang.
3. Klik dua kali start-studio.cmd. Pada penggunaan pertama, koneksi internet diperlukan untuk mengunduh dependensi dan FFmpeg.
4. Buka http://localhost:3210 di Chrome/Edge. Biarkan terminal server tetap berjalan.
5. Buka Pengaturan untuk memasukkan API key AI, lalu Avatar & suara untuk memilih karakter dan suara.

TIKTOK TANPA EULER
Pilih TikTok > Hubungkan chat > masukkan username akun yang sedang LIVE.
Browser pembaca terbuka otomatis. Jika diminta login/CAPTCHA, selesaikan sendiri di browser tersebut.
Aktifkan Balas otomatis setelah chat tersambung dan AI siap.
Pembaca TikTok masih eksperimental; belum terverifikasi dengan komentar LIVE akun pengguna.
Stream key tetap diperlukan untuk mengirim video/audio ke TikTok. Username hanya untuk pembacaan chat.

SUARA OMNIVOICE (OPSIONAL)
Suara Windows dapat digunakan terlebih dahulu.
Untuk OmniVoice, pasang uv lalu jalankan setup-omnivoice.ps1 mengikuti README.md.
Instalasi Python/PyTorch dan model membutuhkan unduhan beberapa GB serta RAM/VRAM yang memadai.

ISI PAKET
Kode aplikasi, UI, tes, package-lock.json, skrip mulai/instalasi, dokumentasi, serta lisensi.
Paket ini bukan aplikasi portable offline: Node.js, browser, dependensi npm, lingkungan Python, dan model perlu tersedia/diinstal di komputer tujuan.
Kredensial, stream key, cookie/sesi login, data avatar pribadi, rekaman suara, node_modules, .venv, dan cache model tidak disertakan.
