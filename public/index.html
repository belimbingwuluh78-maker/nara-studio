Koneksi siaran

Buka platform ↗

Satu platform per siaran. Disimpan di memori server sampai studio dihentikan. Mengganti platform menghapus tujuan dan key sebelumnya.

Hubungkan YouTube

Aktivasi Google diperlukan satu kali untuk studio milikmu.

Setelah aktivasi, cukup klik Login dengan Google dan pilih akun. Password Gmail hanya dimasukkan di halaman resmi Google.

  1. Buat project & aktifkan YouTube

    Buka Google Cloud, buat project bernama Nara Studio dan pilih project tersebut. Di Library, cari YouTube Data API v3 lalu klik Enable.

  2. Daftarkan aplikasi & akun penguji

    Buka Google Auth Platform → Get started / Branding. Isi nama Nara Studio dan email kontakmu. Pilih audience External. Di Audience → Test users, tambahkan Gmail pemilik channel YouTube. Biarkan status Testing untuk pemakaian sendiri.

  3. Buat client Google

    Di Clients → Create client, pilih Web application. Pada Authorized redirect URIs, tambahkan alamat ini persis:

    Klik Create, lalu Download JSON pada client tersebut.

  4. Impor file & login

    Pilih file JSON yang baru diunduh. Konfigurasi disimpan hanya di laptop ini; tidak perlu mengedit kode atau restart.

Jangan bagikan file konfigurasi Google atau folder data studio.

Jika Google masih menolak login

403 / access_denied: pastikan Gmail terdaftar sebagai test user. redirect_uri_mismatch: samakan alamat kembali di atas. API disabled: aktifkan YouTube Data API v3 pada project yang sama. Gunakan Chrome atau Edge biasa untuk login.

Login dengan Google

Selesaikan pemilihan akun dan izin YouTube di browser utama.

Studio akan mendeteksi koneksi secara otomatis. Jika browser tidak terbuka, salin tautan lalu buka di Chrome atau Edge.

Tautan berlaku 10 menit. Jangan bagikan tautan ini.
