Connect YouTube

Set up Google once for your studio.

After setup, click Sign in with Google and choose your account. Enter your Google password only on the official Google page.

  1. Create a project & enable YouTube

    Open Google Cloud, create a project named Nara Studio, and select it. In Library, search for YouTube Data API v3, then click Enable.

  2. Register the app & test accounts

    Open Google Auth Platform → Get started / Branding. Enter Nara Studio and your contact email. Select the External audience. Under Audience → Test users, add the Google account that owns the YouTube channel. Keep the status as Testing for personal use.

  3. Create a Google client

    Under Clients → Create client, select Web application. Under Authorized redirect URIs, add this exact address:

    Click Create, then Download JSON for that client.

  4. Import the file & sign in

    Choose the JSON file you downloaded. The configuration is saved only on this computer; no code edits or restart are needed.

Do not share the Google configuration file or the studio data folder.

If Google still rejects sign-in

403 / access_denied: make sure your Google account is listed as a test user. redirect_uri_mismatch: match the redirect URI shown above. API disabled: enable YouTube Data API v3 in the same project. Use a regular Chrome or Edge window to sign in.

Sign in with Google
